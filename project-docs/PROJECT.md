# BEAUTY NOTE

## Что это за проект

BEAUTY NOTE — учебный React-проект приложения-блокнота для косметолога и клиента.

Главная цель проекта — использовать его как практику во время изучения React, а позже TypeScript и других технологий.

## Как мы учимся на проекте

Новая тема изучается по схеме:

1. Сначала понять теорию.
2. Сделать маленькую отдельную практику.
3. Применить эту же тему в BEAUTY NOTE.
4. Не использовать в проекте технологии, которые ещё не разобраны хотя бы на базовом уровне.

## Важно

Проект развивается вместе с моими знаниями.

На текущем этапе основной фокус — React.

Backend, база данных, авторизация, AI и другие сложные части пока не добавляются, пока до них не дойдёт обучение.
