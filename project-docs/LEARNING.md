## Практика на проекте BEAUTY NOTE

Проект ещё не создан.

Практику начинаем с самого начала:

- создаём React-проект;
- разбираем структуру файлов;
- устанавливаем только необходимые зависимости;
- учимся запускать проект;
- разбираемся, где и зачем пишется React-код.

После этого начинаем применять изученные темы React непосредственно в BEAUTY NOTE.
