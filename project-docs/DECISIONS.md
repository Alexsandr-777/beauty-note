# Решения по проекту

## 11.08.2026

### Решение

Сначала изучаем React на проекте BEAUTY NOTE.

### Почему

BEAUTY NOTE проще технически и лучше подходит для изучения базового React:

- компоненты;
- props;
- state;
- события;
- формы;
- списки;
- условный рендеринг;
- хуки.

Строительный проект оставляем как следующий более сложный этап после укрепления базы React.

### Важно

Проект BEAUTY NOTE начинаем с нуля:

- сначала создаём React-проект;
- разбираем структуру;
- устанавливаем только нужные зависимости;
- не используем технологии, которые ещё не разобраны.
